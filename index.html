BIOS-Einstellungen (Gigabyte X670)

WICHTIG: Vor BIOS-Änderungen!

  • • Notiere deine aktuellen Einstellungen (Fotos machen)
  • • Ändere immer nur EINE Einstellung, dann testen
  • • Bei Crash: CMOS Reset (siehe unten)
  • • NIEMALS Vcore manuell überschreiben bei X3D!

9800X3D Sicherheitshinweis

Dein Gigabyte X670 ist NICHT in der Hauptrisikogruppe für CPU-Ausfälle (82% waren ASRock). Trotzdem: Immer stabiles BIOS (keine Beta!), konservatives PBO starten.

BIOS aufrufen

  1. 1. PC neustarten
  2. 2. Sofort DEL oder F2 drücken
  3. 3. Im BIOS: F2 für Advanced Mode

1. RAM aktivieren (EXPO)

Pfad im BIOSEinstellungWert
Tweaker (ganz oben)Extreme Memory Profile (X.M.P.)Profile 1

Dein Vorteil

+40% RAM Speed

DDR5-4800 → DDR5-6000 MHz. Mehr FPS in CPU-limitierten Szenarien, schnellere Ladezeiten.

EXPO verifizieren nach Neustart:

  • • CPU-Z: Tab "Memory" → DRAM Frequency sollte 3000 MHz zeigen (= 6000 MT/s)
  • • HWiNFO64: Memory → Clock sollte 3000 MHz sein
  • • Task Manager: Leistung → Arbeitsspeicher → Geschwindigkeit: 6000 MHz

2. Resizable BAR

PfadEinstellungWert
Settings → IO PortsAbove 4G DecodingEnabled
Settings → IO PortsResizable BAREnabled
BootCSM SupportDisabled

Dein Vorteil

+5-15% FPS

CPU kann auf den gesamten VRAM zugreifen statt nur 256MB. Weniger Stutter bei großen Texturen.

Resizable BAR verifizieren

Option 1 - GPU-Z: GPU-Z starten → "Advanced" Tab → "Resizable BAR" sollte "Enabled" zeigen

Option 2 - NVIDIA: NVIDIA Control Panel → Systeminformationen → "Resizable BAR: Ja"

Option 3 - CMD:

nvidia-smi -q | findstr "Resizable"

3. Global C-State Control (KRITISCH!)

PfadEinstellungWert
Settings → AMD CBS → SMU Common Options → CPPCGlobal C-State ControlEnabled (NICHT Auto!)

Dein Vorteil

Kein Micro-Stutter!

Behebt das berüchtigte X3D Stutter-Problem. CPU bleibt responsive ohne Energiesparmodus-Lags.

"Auto" bei X3D CPUs verursacht oft Micro-Stutters wenn die CPU aus dem Tiefschlaf aufwacht. Manuell "Enabled" = Problem gelöst!

4. PBO (Precision Boost Overdrive)

BIOS-Pfad: Tweaker → Advanced CPU Settings → Precision Boost Overdrive

EinstellungWertErklärung
Precision Boost OverdriveAdvancedErlaubt manuelle Einstellungen
PBO LimitsMotherboardNutzt Mainboard-Limits (sicher)
PBO Scalar1x (Start!)Höhere Werte = mehr Spannung/Hitze
Max CPU Boost Clock Override+200 MHzErlaubt Boost bis ~5.4 GHz

Dein Vorteil

+200 MHz Boost

CPU darf höher takten wenn Temperaturen es erlauben. Mehr Single-Thread Performance für Gaming.

Nach Aktivierung: Installiere den AMD Chipset Driver → enthält den "3D V-Cache Performance Optimizer" der automatisch optimiert!

5. Curve Optimizer (Mit 360mm AIO)

BIOS-Pfad: Tweaker → Advanced CPU Settings → PBO → Curve Optimizer

EinstellungWertHinweis
Curve OptimizerAll CoresGleicher Wert für alle Kerne
All Core Curve Optimizer SignNegativeUndervolting (weniger Hitze)

Dein Vorteil

-10°C Kühler

Gleiche Performance bei weniger Spannung. CPU läuft kühler und leiser, kann länger boosten.

Stabilität testen (Schritt für Schritt)

  1. 1. Starte mit -15, speichern, neustarten
  2. 2. Cinebench R24: 10-Minuten Multi-Core Test
  3. 3. OCCT: CPU Test, 30 Minuten, auf Fehler achten
  4. 4. Wenn stabil: Erhöhe auf -20, wieder testen
  5. 5. Bei Crash/Bluescreen: Wert um 5 erhöhen (z.B. -20 → -15)

Typische stabile Werte: -15 bis -25. Manche erreichen -30, aber jede CPU ist anders! Besser stabil als maximal.

CMOS Reset (wenn PC nicht mehr bootet)

  1. 1. PC ausschalten, Netzteil-Schalter auf OFF
  2. 2. CMOS-Jumper finden (neben der Batterie auf dem Mainboard)
  3. 3. Jumper für 10 Sekunden auf Position 2-3 setzen (oder Pins mit Schraubenzieher brücken)
  4. 4. Jumper zurück auf 1-2, Netzteil an, PC starten
  5. Alternative: CMOS-Batterie (CR2032) für 30 Sekunden entfernen

Windows 11 24H2 Optimierungen

VBS/Memory Integrity deaktivieren

Virtualization-Based Security prüft jeden Speicherzugriff auf Malware. Gut für Firmen-PCs, aber kostet Gaming-Performance.

Dein Vorteil

+5-15% FPS

Besonders in CPU-limitierten Games wie CS2, Valorant, Fortnite.

Sicherheitshinweis

Reduziert Windows-Sicherheit. Nur für reine Gaming-PCs empfohlen.

Windows 11 24H2

Alle 4 Schritte nötig! Microsoft hat VBS schwerer deaktivierbar gemacht.

  1. 1
    Memory Integrity deaktivieren

    Windows-Taste → "Kernisolierung" eingeben → Enter

    Oder: Einstellungen → Datenschutz & Sicherheit → Windows-Sicherheit → Gerätesicherheit → Kernisolierung

    → Speicherintegrität: AUS

  2. 2
    VBS via Registry deaktivieren

    Rechtsklick auf Start → "Terminal (Administrator)" → Folgenden Befehl eingeben:

    reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\DeviceGuard" /v EnableVirtualizationBasedSecurity /t REG_DWORD /d 0 /f
  3. 3
    Windows Hello VBS deaktivieren (NEU für 24H2!)

    Im gleichen Terminal:

    reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\DeviceGuard\Scenarios\WindowsHello" /v Enabled /t REG_DWORD /d 0 /f
  4. 4
    Hypervisor deaktivieren

    Im gleichen Terminal:

    bcdedit /set hypervisorlaunchtype off
  5. 5
    PC neustarten und verifizieren

    Nach Neustart: Win + R → msinfo32 → Enter

    Suche nach "Virtualization-based security" → sollte "Nicht aktiviert" zeigen

VBS wieder aktivieren (falls Probleme)

bcdedit /set hypervisorlaunchtype auto

Dann PC neustarten und Memory Integrity wieder aktivieren.

RAM-Optimierung

DDR5-6000 CL30 mit 2x32GB ist der perfekte Sweet Spot für AM5. RAM-Optimierung passiert im BIOS durch EXPO!

Was ist EXPO?

AMD EXPO aktiviert automatisch die beworbene RAM-Geschwindigkeit (6000MHz) und optimierte Timings (CL30).

Dein Vorteil

+25% Speed

4800 → 6000 MHz. Bessere 1% Lows, schnellere Ladezeiten.

RAM Slot Konfiguration

A1

leer

A2

32GB

CPU
B2

32GB

B1

leer

Immer A2 + B2 verwenden (zweite Slots von der CPU) für optimales Dual Channel!

Dual Channel

2x Bandbreite vs Single Channel. Wichtig für Gaming-Performance!

FCLK 1:1 Ratio

3000MHz FCLK = optimale Infinity Fabric Latenz. Wird von EXPO automatisch gesetzt!

Nicht 4 Sticks!

4 Sticks = Downclocking auf ~5600MHz. Memory Controller Limit!

  1. 1
    BIOS aufrufen

    PC neustarten → ENTF mehrfach drücken

    Speichern

    F10 → "Save & Exit". PC startet evtl. 2-3x neu (Memory Training).

Verifizieren

Task Manager → Leistung → RAM → sollte 6000 MHz zeigen

BIOS Update (Q-Flash)

BIOS-Updates nur wenn nötig - "Never change a running system". Q-Flash ist die sicherste Methode für Gigabyte Mainboards.

Wann updaten?

Nur bei Problemen

CPU-Support, Stabilität, kritische Fixes

Schritt-für-Schritt Anleitung

1

BIOS herunterladen

  1. • Gigabyte Support-Seite öffnen
  2. • Neueste stabile Version (nicht Beta!)
  3. • ZIP herunterladen & entpacken
  4. • Datei: X670GAMINGXAX.Fxx
2

USB-Stick vorbereiten

  1. • USB-Stick (mind. 1GB) anschließen
  2. • Formatieren: FAT32
  3. • BIOS-Datei ins Root kopieren
  4. • Nicht in Unterordner!
3

Q-Flash starten

  1. • PC neustarten mit USB-Stick
  2. • DEL drücken → BIOS
  3. • F8 für Q-Flash
  4. • Oder: Save & Exit → Q-Flash
4

BIOS flashen

  1. • "Update BIOS" wählen
  2. • USB-Stick → BIOS-Datei auswählen
  3. • "Yes" bestätigen
  4. • WARTEN! Nicht ausschalten!
