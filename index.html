Technische Begriffe erklärt

EXPO / XMP

Extended Profiles for Overclocking – AMD's Pendant zu Intel XMP. Aktiviert automatisch die beworbene RAM-Geschwindigkeit (z.B. 6000MHz statt Standard 4800MHz) und optimierte Timings.

PBO (Precision Boost Overdrive)

AMD-Technologie die der CPU erlaubt, über die Standard-Boost-Takte zu gehen. "Enhancement" gibt mehr Spielraum, "+200MHz Override" erhöht das Maximum.

Curve Optimizer

Untervoltet die CPU pro Kern. Negative Werte (-10 bis -30) = weniger Spannung = kühlere Temps + höhere Boosts. Start konservativ bei -10!

C-States (Global C-State Control)

CPU-Stromsparmodi. Bei 9800X3D MUSS dies auf "Enabled" stehen (nicht Auto!), sonst entstehen Micro-Stutters durch falsche Thread-Zuweisung.

Resizable BAR (Re-BAR)

Erlaubt der CPU direkten Zugriff auf den gesamten VRAM der GPU. Bringt 5-10% mehr FPS in vielen Spielen. Benötigt: UEFI Boot + CSM Disabled.

CSM (Compatibility Support Module)

Legacy BIOS-Modus für alte Betriebssysteme. Muss für Resizable BAR und Secure Boot deaktiviert sein. Windows 11 braucht es nicht.

CMOS Reset (Notfall)

Wenn PC nicht mehr bootet

  1. 1. PC ausschalten, Netzteil-Schalter auf OFF
  2. 2. CMOS-Jumper finden (neben der Batterie) oder Clear CMOS Button hinten am I/O
  3. 3. Jumper für 10 Sekunden auf Position 2-3 setzen (oder Button 5 Sek drücken)
  4. 4. Netzteil an, PC starten → BIOS ist zurückgesetzt

Nur die .F39 / .F40 / etc. Datei (ca. 15-20 MB). Der Buchstabe "F" + Zahl = BIOS-Version. Die anderen Dateien (EFI, .nsh, .efi) sind für EFI-Shell Update und werden nicht benötigt.
