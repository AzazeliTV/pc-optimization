BIOS-Einstellungen (Gigabyte X670)

9800X3D Sicherheitshinweis

Dein Gigabyte X670 ist NICHT in der Hauptrisikogruppe für CPU-Ausfälle (82% waren ASRock). Trotzdem: Immer stabiles BIOS (keine Beta!), konservatives PBO starten.

1. RAM aktivieren (EXPO)

Pfad Einstellung Wert
Tweaker XMP/EXPO Profile Profile 1

Aktiviert automatisch DDR5-6000MHz CL30 mit FCLK 3000MHz (1:1 Ratio).

2. Global C-State Control (KRITISCH!)

Pfad Einstellung Wert
Settings → AMD CBS → SMU Common Options → CPPC Global C-State Control Enabled (NICHT Auto!)

Manuell auf "Enabled" setzen eliminiert Micro-Stuttering bei X3D CPUs! "Auto" kann Probleme verursachen.

3. PBO (Precision Boost Overdrive)

Einstellung Wert Erklärung
Precision Boost Overdrive Advanced Volle Kontrolle
PBO Limits Motherboard Nutzt Mainboard-Limits
PBO Scalar 1x - 10x 1x für Stabilität, höher für mehr Boost
Boost Clock Override +200MHz Erhöht maximales Boost-Limit

4. Curve Optimizer (Mit 360mm AIO empfohlen)

Einstellung Wert Hinweis
Curve Optimizer All Cores Einfacher Start
Sign Negative Undervolting
Magnitude -15 bis -20 (Start) Konservativ beginnen!

Stabilität testen!

Starte mit -15 bis -20 und teste mit Cinebench R23, OCCT oder Y-Cruncher. Viele User mit 360mm AIO erreichen -25 bis -30 stabil, aber jede CPU ist anders. Bei Crashes: Wert erhöhen (z.B. -20 → -15).

Windows 11 24H2 Optimierungen

VBS/Memory Integrity deaktivieren (5-15% FPS!)

Windows 11 24H2 Update

VBS ist komplexer zu deaktivieren geworden. Es gibt jetzt eine zusätzliche Windows Hello VBS-Abhängigkeit die auch deaktiviert werden muss!

Schritt 1: Memory Integrity deaktivieren

  1. Einstellungen → Datenschutz & Sicherheit → Windows-Sicherheit
  2. Gerätesicherheit → Kernisolierung → Details
  3. Speicherintegrität → AUS

Schritt 2: VBS via Registry deaktivieren (Admin CMD)

reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\DeviceGuard" /v EnableVirtualizationBasedSecurity /t REG_DWORD /d 0 /f

Schritt 3: Windows Hello VBS deaktivieren (NEU für 24H2!)

reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\DeviceGuard\Scenarios\WindowsHello" /v Enabled /t REG_DWORD /d 0 /f

Schritt 4: Hypervisor deaktivieren

bcdedit /set hypervisorlaunchtype off

PC neustarten. Prüfen mit msinfo32 → "Virtualization-based security" sollte "Not enabled" zeigen.
