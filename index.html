BIOS Update mit Q-Flash (Gigabyte)

NIEMALS BIOS über Windows updaten!

Gigabyte Control Center, @BIOS oder andere Windows-Tools können das BIOS beschädigen wenn Windows abstürzt. Immer Q-Flash im BIOS selbst nutzen!

Schritt 1: BIOS herunterladen

  1. 1. Gehe zu: Gigabyte X670 Gaming X AX Support-Seite
  2. 2. Unter "BIOS" die neueste stabile Version finden (NICHT Beta!)
  3. 3. Auf das Download-Symbol klicken → ZIP-Datei herunterladen
  4. 4. ZIP entpacken → Du bekommst eine Datei wie X670GAMINGXAX.F12

Schritt 2: USB-Stick vorbereiten

  1. 1. USB-Stick (mind. 1GB) an PC anschließen
  2. 2. USB-Stick formatieren: Rechtsklick → Formatieren → FAT32 wählen → Starten
  3. 3. Die BIOS-Datei (z.B. X670GAMINGXAX.F12) auf den USB-Stick kopieren
  4. 4. Wichtig: Datei direkt ins Root-Verzeichnis, NICHT in einen Ordner!

Schritt 3: Q-Flash starten

  1. 1. PC neustarten, USB-Stick eingesteckt lassen
  2. 2. Beim Booten DEL drücken um ins BIOS zu kommen
  3. 3. Im BIOS: Drücke F8 für Q-Flash
  4. 4. Oder: Gehe zu Save & Exit → Q-Flash

Schritt 4: BIOS flashen

  1. 1. Wähle "Update BIOS"
  2. 2. Wähle deinen USB-Stick aus der Liste
  3. 3. Wähle die BIOS-Datei (z.B. X670GAMINGXAX.F12)
  4. 4. Bestätige mit "Yes" oder Enter
  5. 5. WARTEN! PC nicht ausschalten! Dauert 2-5 Minuten
  6. 6. PC startet automatisch neu

Schritt 5: Nach dem Update

  1. 1. PC bootet ins BIOS (Einstellungen wurden zurückgesetzt!)
  2. 2. Alle Einstellungen neu konfigurieren: EXPO, PBO, Curve Optimizer, etc.
  3. 3. Speichern mit F10 → Yes
  4. 4. BIOS-Version prüfen: Steht oben rechts im BIOS

Wann BIOS updaten?

  • • JA: Bei Stabilitätsproblemen, neuer CPU-Support, kritischen Fixes
  • • NEIN: "Never change a running system" - wenn alles läuft, nicht updaten!

Tipp: Mache Fotos von deinen aktuellen BIOS-Einstellungen BEVOR du updatest! Nach dem Update sind alle Einstellungen auf Standard zurückgesetzt.

BIOS-Einstellungen (Gigabyte X670)

WICHTIG: Vor BIOS-Änderungen!

  • • Notiere deine aktuellen Einstellungen (Fotos machen)
  • • Ändere immer nur EINE Einstellung, dann testen
  • • Bei Crash: CMOS Reset (siehe unten)
  • • NIEMALS Vcore manuell überschreiben bei X3D!

9800X3D Sicherheitshinweis

Dein Gigabyte X670 ist NICHT in der Hauptrisikogruppe für CPU-Ausfälle (82% waren ASRock). Trotzdem: Immer stabiles BIOS (keine Beta!), konservatives PBO starten.

BIOS aufrufen

  1. 1. PC neustarten
  2. 2. Sofort DEL oder F2 drücken
  3. 3. Im BIOS: F2 für Advanced Mode

Pfad im BIOSEinstellungWert

EXPO verifizieren nach Neustart:

  • • CPU-Z: Tab "Memory" → DRAM Frequency sollte 3000 MHz zeigen (= 6000 MT/s)
  • • HWiNFO64: Memory → Clock sollte 3000 MHz sein
  • • Task Manager: Leistung → Arbeitsspeicher → Geschwindigkeit: 6000 MHz

Stabilität testen (Schritt für Schritt)

  1. 1. Starte mit -15, speichern, neustarten
  2. 2. Cinebench R24: 10-Minuten Multi-Core Test
  3. 3. OCCT: CPU Test, 30 Minuten, auf Fehler achten
  4. 4. Wenn stabil: Erhöhe auf -20, wieder testen
  5. 5. Bei Crash/Bluescreen: Wert um 5 erhöhen (z.B. -20 → -15)

Typische stabile Werte: -15 bis -25. Manche erreichen -30, aber jede CPU ist anders! Besser stabil als maximal.

CMOS Reset (wenn PC nicht mehr bootet)

  1. 1. PC ausschalten, Netzteil-Schalter auf OFF
  2. 2. CMOS-Jumper finden (neben der Batterie auf dem Mainboard)
  3. 3. Jumper für 10 Sekunden auf Position 2-3 setzen (oder Pins mit Schraubenzieher brücken)
  4. 4. Jumper zurück auf 1-2, Netzteil an, PC starten
  5. Alternative: CMOS-Batterie (CR2032) für 30 Sekunden entfernen

Windows 11 24H2 Optimierungen

VBS/Memory Integrity deaktivieren (5-15% FPS!)

Sicherheitshinweis

VBS deaktivieren reduziert die Windows-Sicherheit. Nur empfohlen wenn du: keine sensiblen Daten auf dem Gaming-PC hast und der PC nicht im Firmennetzwerk ist.

Windows 11 24H2 Update

VBS ist komplexer zu deaktivieren. Alle 4 Schritte sind nötig!

  1. 1
    Memory Integrity deaktivieren

    Windows-Taste → "Kernisolierung" eingeben → Enter

    Oder: Einstellungen → Datenschutz & Sicherheit → Windows-Sicherheit → Gerätesicherheit → Kernisolierung

    → Speicherintegrität: AUS

  2. 2
    VBS via Registry deaktivieren

    Rechtsklick auf Start → "Terminal (Administrator)" → Folgenden Befehl eingeben:

    reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\DeviceGuard" /v EnableVirtualizationBasedSecurity /t REG_DWORD /d 0 /f
  3. 3
    Windows Hello VBS deaktivieren (NEU für 24H2!)

    Im gleichen Terminal:

    reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\DeviceGuard\Scenarios\WindowsHello" /v Enabled /t REG_DWORD /d 0 /f
  4. 4
    Hypervisor deaktivieren

    Im gleichen Terminal:

    bcdedit /set hypervisorlaunchtype off
  5. 5
    PC neustarten und verifizieren

    Nach Neustart: Win + R → msinfo32 → Enter

    Suche nach "Virtualization-based security" → sollte "Nicht aktiviert" zeigen

VBS wieder aktivieren (falls Probleme)

bcdedit /set hypervisorlaunchtype auto

Dann PC neustarten und Memory Integrity wieder aktivieren.

Warum V-Sync EIN mit G-Sync?

Der Frame-Cap (237) hält FPS immer unter 240Hz → G-Sync ist immer aktiv. V-Sync springt nur ein wenn FPS > 237, was durch den Cap nie passiert. Ergebnis: Tear-Free + minimaler Input Lag!

Jetzt zeigt ein Overlay "G-SYNC On" wenn es aktiv ist (nach Test wieder deaktivieren).

RAM-Optimierung

DDR5-6000 CL30 mit 2x32GB ist der perfekte Sweet Spot für AM5. RAM-Optimierung passiert hauptsächlich im BIOS!

Was ist EXPO?

AMD EXPO (Extended Profiles for Overclocking) ist wie Intel XMP - ein vorkonfiguriertes Profil auf deinen RAM-Sticks. Es aktiviert automatisch die beworbene Geschwindigkeit (6000MHz) und optimierte Timings (CL30).

EXPO im BIOS aktivieren (Gigabyte X670)

  1. 1
    BIOS aufrufen

    PC neustarten → ENTF-Taste mehrfach drücken beim Boot

  2. 2
    EXPO aktivieren

    Tweaker → Extreme Memory Profile (X.M.P.) → Profile 1

    Profile 1 = DDR5-6000 CL30 | Profile 2 = manchmal niedrigere Geschwindigkeit

  3. 3
    Speichern & Neustarten

    F10 drücken → "Save & Exit" bestätigen

    PC startet evtl. 2-3x neu (Memory Training) - das ist normal!

Falls EXPO instabil ist: Wähle stattdessen 5600MHz (falls vorhanden) oder deaktiviere EXPO vorübergehend. Manche Mainboards brauchen ein BIOS-Update für stabiles 6000MHz.

EXPO verifizieren (nach dem Neustart)

ToolWo schauenErwarteter Wert
Task ManagerLeistung → Arbeitsspeicher6000 MHz
CPU-ZTab "Memory" → DRAM Frequency3000 MHz (= 6000 MT/s)
HWiNFO64Memory → Clock3000 MHz

Hinweis: DDR5-6000 bedeutet 6000 MT/s (Mega-Transfers). Die tatsächliche Taktfrequenz ist die Hälfte (3000 MHz).

Wichtige RAM-Regeln

  • FCLK 3000MHz (1:1 Ratio) = beste Latenz, wird automatisch von EXPO gesetzt
  • 2 Sticks in A2 + B2 = optimal für Dual Channel (nicht die direkt neben CPU!)
  • EXPO Profile 1 aktiviert alle optimierten Timings automatisch

Verwende NICHT 4 RAM-Sticks! Dies erfordert Downclocking auf ~5600MHz wegen erhöhter Last auf dem Memory Controller.

SSD-Wartung (Samsung 990 PRO)

KRITISCH: Firmware prüfen!

Frühere Firmware-Versionen hatten einen Bug der die SSD-Lebensdauer schnell reduziert! Mindestens Firmware 5B2QJXF7 oder neuer.

Firmware prüfen (Schritt für Schritt)

  1. 1Samsung Magician herunterladen und installieren
  2. 2Samsung Magician starten → Deine 990 PRO auswählen
  3. 3Auf der Hauptseite steht "Firmware" mit Versionsnummer
  4. 4Vergleiche: Muss 5B2QJXF7 oder höher sein (z.B. 5B2QKXF7)
  5. 5Falls älter: Klicke "Update" (PC startet neu!)
