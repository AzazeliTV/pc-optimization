Windows 11 24H2 Optimierungen

VBS/Memory Integrity deaktivieren (5-15% FPS!)

Windows 11 24H2 Update

VBS ist komplexer zu deaktivieren. Windows Hello VBS-Abhängigkeit muss auch deaktiviert werden!

Schritt 1: Memory Integrity deaktivieren

Einstellungen → Datenschutz & Sicherheit → Windows-Sicherheit → Gerätesicherheit → Kernisolierung → Speicherintegrität → AUS

Schritt 2: VBS via Registry (Admin CMD)

reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\DeviceGuard" /v EnableVirtualizationBasedSecurity /t REG_DWORD /d 0 /f

Schritt 3: Windows Hello VBS (NEU für 24H2!)

reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\DeviceGuard\Scenarios\WindowsHello" /v Enabled /t REG_DWORD /d 0 /f

Schritt 4: Hypervisor deaktivieren

bcdedit /set hypervisorlaunchtype off

PC neustarten. Prüfen mit msinfo32 → "Virtualization-based security" = "Not enabled"

RAM-Optimierung

DDR5-6000 CL30 mit 2x32GB ist der perfekte Sweet Spot für AM5:

  • FCLK 3000MHz (1:1 Ratio) = beste Latenz
  • 2 Sticks = optimal (nicht 4!)
  • EXPO Profile 1 aktiviert alles automatisch

Verwende NICHT 4 RAM-Sticks! Dies würde ein Downclocking auf ~5600MHz erfordern.
