EinstellungWertHinweis
Curve OptimizerAll CoresEinfacher Start

⚠️
Stabilität testen! Starte mit -10 bis -15 und teste mit Cinebench R23, OCCT oder Y-Cruncher. Viele User mit 360mm AIO erreichen -20 bis -30 stabil, aber jede CPU ist anders. Bei Crashes: Wert erhöhen (z.B. -15 → -10).

Pro-Tipp: Für maximale Stabilität Per-Core Curve Optimizer nutzen. Ryzen Master "Derive" Funktion kann als Ausgangspunkt helfen.

Windows 11 24H2 Optimierungen

VBS/Memory Integrity deaktivieren (5-15% FPS!)

⚠️
Windows 11 24H2 Update: VBS ist komplexer zu deaktivieren geworden. Es gibt jetzt eine zusätzliche Windows Hello VBS-Abhängigkeit die auch deaktiviert werden muss!

Schritt 1: Memory Integrity deaktivieren

  1. Einstellungen → Datenschutz & Sicherheit → Windows-Sicherheit
  2. Gerätesicherheit → Kernisolierung → Details
  3. Speicherintegrität → AUS

Schritt 2: Tamper Protection deaktivieren (für Registry-Änderungen)

  1. Windows-Sicherheit → Viren- & Bedrohungsschutz
  2. Einstellungen verwalten → Manipulationsschutz → AUS

Schritt 3: VBS via Registry komplett deaktivieren (CMD als Admin)

reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\DeviceGuard" /v EnableVirtualizationBasedSecurity /t REG_DWORD /d 0 /f

Schritt 4: Windows Hello VBS-Abhängigkeit deaktivieren (NEU für 24H2!)

reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\DeviceGuard\Scenarios\WindowsHello" /v Enabled /t REG_DWORD /d 0 /f

Schritt 5: Hypervisor deaktivieren

bcdedit /set hypervisorlaunchtype off

PC neustarten. Prüfen mit msinfo32 → "Virtualization-based security" sollte "Not enabled" zeigen.

ℹ️
Hinweis: Das Deaktivieren von VBS kann Windows Hello Face Recognition beeinträchtigen. PIN-Login funktioniert weiterhin.

RAM-Optimierung

DDR5-6000 CL30 mit 2x32GB ist der perfekte Sweet Spot für AM5:

  • FCLK 3000MHz (1:1 Ratio) = beste Latenz
  • 2 Sticks = optimal (nicht 4!)
  • EXPO Profile 1 aktiviert alles automatisch
🚫
Verwende NICHT 4 RAM-Sticks! Dies würde ein Downclocking auf ~5600MHz erfordern.

SSD-Wartung (Samsung 990 PRO)

🚨
KRITISCH: Frühere Firmware-Versionen hatten schnelle Health-Verschlechterung! Stelle sicher, dass du Firmware 5B2QJXF7 oder neuer hast. Prüfe in Samsung Magician!

Samsung Magician Einstellungen

  • Firmware auf neueste Version updaten
  • Performance Optimization → "Full Performance Mode"
  • Drive Health regelmäßig prüfen (sollte "Good" sein)
  • Temperatur sollte unter 70°C bleiben
⚠️
Falls Firmware-Update fehlschlägt: Samsung ISO herunterladen und via USB booten. Intel VMD kann Updates blockieren.
